# Skill Track – Student Learning Management System
Project Overview

**Skill Track** is a web-based Student Learning Management System designed to help students manage their learning activities in an organized and simple way.
The project provides an interactive interface where students can explore courses, track their learning progress, and access important learning information.

#🎯 Objectives

- Provide a user-friendly learning platform.
- Display available courses and learning resources.
- Help students track their learning progress.
- Create an attractive and responsive web interface.
- Demonstrate practical usage of HTML, CSS, and JavaScript.

#🛠️ Technologies Used

- **HTML5** – Structure of the web pages
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactivity and dynamic functionality
- **Google Fonts** – Typography

## ✨ Features

- Responsive navigation bar
- Attractive home page
- Course/learning sections
- Student-friendly interface
- Interactive buttons and elements
- Progress tracking interface
- Responsive design for different screen sizes
- Clean and simple user interface

## 📚 Learning Outcomes

Through this project, I practiced:
- Creating web pages using HTML
- Styling websites using CSS
- Using JavaScript for interaction
- Creating responsive layouts
- Organizing a web development project
- Uploading and managing projects using GitHub
